## Requisitos do Projeto

### Requisitos Funcionais

|ID    | Descrição                | Prioridade |
|-------|---------------------------------|----|
| RF-01 |  Oferecer recursos visuais (animações, ilustrações ou personagens) para explicar os exames                    | Alta | 
| RF-02 |  Permitir que responsáveis acompanhem ou auxiliem na explicação                    | Alta |
| RF-03 |  Disponibilizar explicações específicas para diferentes tipos de exame                   | Média | 
| RF-04 |  Reduzir o medo da criança por meio de linguagem amigável e interativa                    | Alta |
| RF-05 |  Possibilitar o uso em dispositivos móveis (tablet/celular)                    | Média | 
| RF-06 |  Exibir explicações simples e lúdicas sobre exames médicos (ex: sangue, tomografia)                   | Alta |

**Prioridade: Alta / Média / Baixa. 

### Requisitos não Funcionais

|ID      | Descrição               |Prioridade |
|--------|-------------------------|----|
| RNF-01 |  Interface deve ser intuitiva e fácil de usar para crianças                    | Alta | 
| RNF-02 |  O sistema deve ser acessível (cores suaves, fontes legíveis, sem estímulos agressivos)                    | Alta |
| RNF-03 |  Sons e animações devem ser opcionais (principalmente para crianças sensíveis)                    | Média | 
| RNF-04 |  Garantir segurança e privacidade dos dados dos usuários                    | Média |
| RNF-05 |  O sistema deve funcionar offline ou com baixa conexão                    | Baixa | 
| RNF-06 |  Compatibilidade com diferentes dispositivos (celular, tablet, computador)                    | Média |

**Prioridade: Alta / Média / Baixa.
